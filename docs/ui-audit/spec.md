版本：0.4.1-local 真机走查（Xiaomi 12S Ultra / Android 15 / API 35）
范围：首页、右上菜单、权限弹层、数据源弹层、编辑行程、地铁选线/选站、实时看板、最近行程、删除/结束流程
证据：`%TEMP%\cc-ui\01-home.png` … `19-new-trip.png`（截图）与同名 `.xml`（控件树）

## 1. 目标与判定标准

以真实用户的认知负担与情绪体验为验收标准，而非“功能可用”。走查覆盖六个维度：

1. 信息架构（IA）：入口是否可发现、分组是否符合心智、优先级是否正确。
2. 用户流程：层级返回、状态保留、异常分支是否有出口。
3. 操作效率：高频操作步数、重复入口、滚动位置、误触成本。
4. 反馈机制：操作结果、加载/失败、破坏性操作确认与可恢复性。
5. 视觉层级：主次对比、可点击 affordance、遮挡与裁切。
6. 组件一致性：同类控件尺寸/颜色/语义一致，危险动作有危险语义。

严重度：

- **P0**：数据丢失、隐私泄露、破坏性操作不可逆且易误触、核心流程中断。
- **P1**：明显误导或高概率误操作，显著增加认知负担，破坏信任。
- **P2**：可用但不够好，影响效率或精致度。
- **P3**：打磨项。

## 4. P0/P1 修复规格（决策已定）

### A1 未保存保护（P0）

- 文件：`ui/App.kt`、`ui/TripEditor.kt`
- 改动：
  1. `App` 增加 `var dirty by remember { mutableStateOf(false) }`；`onNew`/`onEdit` 置 false，`TripEditor.onChange` 置 true，`onSaved` 置 false；从选线器 `addCandidate` 也置 true。
  2. `TripEditor` 新增参数 `dirty: Boolean`。内部 `var confirmLeave`，`requestBack()`：`dirty` 为真时弹 `AlertDialog`（标题“放弃未保存的修改？”，正文“离开后本次修改不会保留。”，按钮“继续编辑 / 放弃修改”），否则 `onBack()`。
  3. `GlassPage(onBack = ::requestBack)`，并新增 `BackHandler { requestBack() }`。
- 验收：改名称→进选线器→返回→按返回键，弹确认；选“继续编辑”留在原页；选“放弃修改”回首页且数据未变。

### A2 选线器层级返回（P0）

- 文件：`ui/Pickers.kt`（`BusPicker`、`MetroPicker`、`ShuttleEditor`）、`ui/App.kt`
- 改动：每个选线器按自身 stage 安装 `BackHandler(enabled = stage != 初始 stage)`，回到上一 stage（复用 stage 内已保存的 `back` 字段）；处于初始 stage 时不拦截，交给 `App` 现有 `BackHandler` 回编辑页。`ShuttleEditor` 安装 `BackHandler { onBack() }`。
- 验收：地铁“选上车站”按返回→线路列表（不是编辑页）；再按返回→编辑页；公交各阶段同理。

### A3 结束行程：确认 + 反馈 + 无效记录过滤（P0）

- 文件：`ui/LiveBoard.kt`、`ui/HomeScreen.kt`
- 改动：
  1. “结束行程”从与“确认上车”并排改为下方独立 44dp 低强调文字按钮；点击弹确认（“结束本次行程？结束后不再提醒，可在最近行程中补录节点。”）。
  2. `LiveBoard` 新增 `onStopped: (() -> Unit)? = null`；真正结束后回调，`HomeScreen` 用它 `showSnackbar("行程已结束")`；演示模式不弹确认、不提示。
  3. `HomeScreen` 的 `lastRun` 过滤：节点数 <2 或首尾跨度 <2 分钟则不展示“最近行程”。
- 验收：开始→结束需二次确认；结束后有 Snackbar；不会再出现 6 个“—”的最近行程卡。

### A4 删除整段确认（P0）

## 7. 风险与非目标

- 返回键依赖 Compose `BackHandler` 注册顺序：内层（选线器/编辑页）先消费，`App` 仅兜底；需真机验证不出现“返回无响应”。
- 移除 FAB 属视觉变更，需确认用户接受标题栏 `+`。
- 本轮不改动定时唤起、通知胶囊、地理围栏等后台逻辑；API 35 无法验证 Android 16 通知胶囊。
- 不做整体视觉重设计，仅修正层级、语义与误触。
