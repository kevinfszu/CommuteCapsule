# 通勤胶囊：高德选点指定出发地/目的地

## Summary

新建/编辑行程时，出发地、目的地都可以通过高德选点指定：

1. 复用现有高德 **Web 服务 Key**（设置里已有），新增输入提示、周边地点、逆地理编码、静态地图预览四个接口；不接地图 SDK、不加新依赖。
2. 新增全屏选点组件：当前定位、关键词搜索、周边地点、静态地图预览。所有坐标统一转 WGS-84 后落库。
3. 出发地：保留「重新定位」，增加「选择地点」，选完只改坐标与名称，不改变「按时间/离开出发地」的唤起方式。
4. 行程新增目的地字段（名称 + 坐标，可清除），在行程编辑页展示。
5. 目的地参与到达判定：在目的地 150 米内持续驻留满 3 分钟、且已下车、地铁末段已出站，才自动结束行程。

不做：高德 Android SDK / JS 地图拖点；不改上/下车站推断；不改公交/班车结束规则。

### B. `app/src/main/java/com/busnotice/commute/AmapData.kt`

新增数据类与 URL/解析（保持无 Android 依赖，可单测）：

```kotlin
/** 高德选点结果：坐标已转成 WGS-84 */
data class PlacePoint(
    val name: String,
    val address: String,
    val lat: Double,
    val lng: Double,
    val distanceM: Int? = null,
)

private const val AMAP = "https://restapi.amap.com/v3"
private fun enc(s: String) = java.net.URLEncoder.encode(s, "UTF-8")

fun inputTipsUrl(key: String, city: String, keywords: String, lat: Double?, lng: Double?): String {
    val base = "$AMAP/assistant/inputtips?key=${enc(key)}&keywords=${enc(keywords)}&city=${enc(city)}&citylimit=false&output=json"
    if (lat == null || lng == null) return base
    val (glat, glng) = wgsToGcj(lat, lng)
    return "$base&location=${"%.6f".format(glng)},${"%.6f".format(glat)}"
}

fun aroundUrl(key: String, lat: Double, lng: Double, radiusM: Int = 1200): String {
    val (glat, glng) = wgsToGcj(lat, lng)
    return "$AMAP/place/around?key=${enc(key)}&location=${"%.6f".format(glng)},${"%.6f".format(glat)}" +
        "&radius=$radiusM&types=${enc("商务住宅|公司企业|地名地址信息|交通设施服务")}" +
        "&offset=20&page=1&extensions=base&output=json"
}

fun regeoUrl(key: String, lat: Double, lng: Double): String {
    val (glat, glng) = wgsToGcj(lat, lng)
    return "$AMAP/geocode/regeo?key=${enc(key)}&location=${"%.6f".format(glng)},${"%.6f".format(glat)}" +
        "&extensions=base&output=json"
}

fun staticMapUrl(key: String, lat: Double, lng: Double, w: Int = 640, h: Int = 320, zoom: Int = 16): String {
    val (glat, glng) = wgsToGcj(lat, lng)
    val p = "${"%.6f".format(glng)},${"%.6f".format(glat)}"
    return "$AMAP/staticmap?key=${enc(key)}&location=$p&zoom=$zoom&size=${w}*${h}" +
        "&markers=${enc("mid,0xE4572E,A:$p")}&output=json"
}

fun parseTips(json: String): List<PlacePoint>
fun parseAround(json: String): List<PlacePoint>
fun parseRegeo(json: String): PlacePoint?
```

解析约定：

- `location` 字段是 `"lng,lat"`（GCJ-02），解析时 `gcjToWgs(lat, lng)`；没有 `location` 的条目（公交线路提示）跳过。
- `status != "1"` 或字段缺失返回空列表 / null，不抛异常。
- `address` 可能是字符串，也可能是数组（`[]`），数组时用 `joinToString("")`。
- 逆地理取 `regeocode.formatted_address`，坐标取请求坐标本身（已是 WGS-84）。

## Assumptions & Decisions

1. 选点方式采用高德 **Web 服务 + 静态地图预览**（用户已确认）；地图不能拖动，点位通过搜索/周边/当前位置确定。
2. 目的地参与到达判定（用户已确认）；不做到站提醒。
3. 出发地选点不自动切换「离开出发地后唤起」，也不改触发半径；半径仍由用户在下面选择。
4. 目的地为可选；不设置时行为与现在完全一致（只认家/公司围栏）。
5. 目的地判定要求「坐过车 + 已下车（`alightAt > 0` 时才有意义）+ 地铁末段已出站」；其中「坐过车」沿用 `neverBoarded`，「出站」沿用 `metroStillInside()`，不新增放行口子。
6. 坐标统一 WGS-84 落库：高德返回 GCJ-02，入库前用现有 `gcjToWgs` 转换。
7. 静态地图与搜索都用现有 Web 服务 Key；Key 未设置时只能使用当前位置选点。
