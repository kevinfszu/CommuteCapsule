# 全站体验走查与统一字阶方案

## 一、概述

对全部 11 个页面（首页、设置、行程记录、算法学习、线路导入、线路详情、高德生成、行程编辑、选公交、选地铁、选班车）做六维度走查，核心产出两件事：

1. 建立唯一的字阶来源 `ui/Type.kt`，终结字号/字重散落。
2. 修复标题三套、11sp 过小、反馈通道三种等 P0/P1 问题；其余整理为可执行待办。

不改业务逻辑、不动数据层。

## 三、目标字阶（唯一来源）

新增 `app/src/main/java/com/busnotice/commute/ui/Type.kt`：

```kotlin
object Type {
    val Display     = TextStyle(fontSize = 28.sp, fontWeight = FontWeight.Bold, lineHeight = 34.sp)
    val PageTitle   = TextStyle(fontSize = 22.sp, fontWeight = FontWeight.Bold, lineHeight = 28.sp)
    val ItemTitle   = TextStyle(fontSize = 17.sp, fontWeight = FontWeight.SemiBold, lineHeight = 22.sp)
    val Section     = TextStyle(fontSize = 15.sp, fontWeight = FontWeight.SemiBold, lineHeight = 20.sp)
    val Body        = TextStyle(fontSize = 14.sp, fontWeight = FontWeight.Normal, lineHeight = 20.sp)
    val BodyDim     = TextStyle(fontSize = 13.sp, fontWeight = FontWeight.Normal, lineHeight = 18.sp)
    val Caption     = TextStyle(fontSize = 12.sp, fontWeight = FontWeight.Normal, lineHeight = 16.sp)
    val Micro       = TextStyle(fontSize = 11.sp, fontWeight = FontWeight.Normal, lineHeight = 14.sp) // 仅 LiveBoard
    val Metric      = TextStyle(fontSize = 16.sp, fontWeight = FontWeight.Bold, fontFeatureSettings = "tnum", lineHeight = 20.sp)
    val MetricLarge = TextStyle(fontSize = 26.sp, fontWeight = FontWeight.Bold, fontFeatureSettings = "tnum", lineHeight = 30.sp)
    val MetricMini  = TextStyle(fontSize = 13.sp, fontWeight = FontWeight.Bold, fontFeatureSettings = "tnum", lineHeight = 18.sp)
}
```

规则：

* 卡片/小节标题 = `Section`（15/600），颜色用 `Fuse.ink(dark).copy(alpha = 0.78f)`，不再是 dim。
* 列表项主标题 = `ItemTitle`（17/600），仅 Records 行、导入列表行使用。
* 正文 14，说明 13，注脚 12；11 只允许出现在 LiveBoard。
* 所有数字统一 `Metric*`，不再手写 `fontSize + Bold + TnumStyle` 组合。
* 颜色继续由 `Fuse` 决定，`Type` 只管字号/字重/行高/等宽。

## 四、具体改动

### 4.1 第一批（P0，子 Agent A）

文件：`Type.kt`（新建）、`GlassKit.kt`、`LearnScreen.kt`、`RecordsScreen.kt`、`HeadwayBandsEditor.kt`、`TripEditor.kt`（仅 `Section`）。

1. **`GlassKit.kt`**
   * `GlassTopBar` 标题改用 `Type.PageTitle`。
   * `SectionLabel` 改为 `Type.Section` + `Fuse.ink(dark).copy(alpha = 0.78f)`，保持 `modifier` 参数不变；`sectionHeader` 随之统一。
   * `TnumStyle` 保留（LiveBoard 依赖），但新增代码不再直接使用。
2. **`LearnScreen.kt`**
   * 删除本地 `CardTitle`，所有调用改为 `SectionLabel(text, modifier)`；`stopSummary` 摘要、总耗时等结论值改用 `Type.Metric`。
   * 11sp 注脚改 `Type.Caption`。
3. **`RecordsScreen.kt`**
   * `RunRow` 行程名 20sp → `Type.ItemTitle`；日期/路线等说明 13sp → `Type.BodyDim`。
   * `WeekCard` 三个统计值 → `Type.Metric`；标签 11sp → `Type.Caption`。
   * 空态标题 16sp → `Type.ItemTitle`。
4. **`HeadwayBandsEditor.kt`**：15sp Bold 的小节标题改用 `SectionLabel`。
5. **`TripEditor.kt`**
   * 私有 `Section` 组合改为调用 `SectionLabel` + 10dp 间距（保留函数，内部走统一 token）。
   * `TimeBox` 26sp → `Type.MetricLarge`。
6. 反馈（仅限本批涉及文件）：Records 删除成功与 Settings 重置地点的 Toast 改为页内提示**不在本批**（P1，见 5.1）。

### 4.2 第二批（P1 字阶迁移，子 Agent B）

文件：`HomeScreen.kt`、`Settings.kt`、`LocationPicker.kt`、`LineImportScreen.kt`、`LineDetailScreen.kt`、`AmapImportScreen.kt`、`Pickers.kt`。

* 只做「等价替换」：把现有字号+字重组合换成最接近的 token，**不改布局、不改文案**。
* 映射规则：28→Display；22→PageTitle；15/16 且是标题→Section（卡内）或 ItemTitle（列表项）；14→Body；13→BodyDim；12→Caption；所有数字→对应 Metric。
* 遇到意义不明的 Text（如纯图标占位、徽标）跳过，在汇报中列出。

### 4.3 不在本轮实现（保留待办）

见第五节。

## 五、后续可执行方案（P1/P2）

1. **统一反馈通道**：`GlassPage` 增加可选 `snackbarHost`；Records 删除、Settings 重置、导入成功等改用页内 Snackbar（2.5s，与 Home 一致）；系统 Toast 仅保留给「离开页面后仍需知晓」的结果。预计改 `GlassKit.kt`、`RecordsScreen.kt`、`Settings.kt`、`LineImportScreen.kt`。
2. **最近行程直达记录**：首页「最近行程」标题行右侧加「全部记录 ›」，点击进入 Records；无记录时不显示。改 `HomeScreen.kt`。
3. **设置分组修正**：把「导出行程记录」从「线路与数据」移到「行程」组。改 `Settings.kt:87-114`。
4. **对话框标题字阶**：统一 20/600（新增 `Type.DialogTitle`），避免 Material 默认 24sp。改 `GlassKit.kt` 及所有 `AlertDialog(title = ...)` 调用。
5. **LiveBoard 独立字阶文档化**：在看板文件顶部注释说明 11/12/13/20/44/80 为黑底看板专用，不参与全站字阶。
6. **可访问性**：所有可点击行补充 `contentDescription`（GlassRow 已带支持），并对纯图标按钮补语义；字号最小 11 仅限看板。

## 六、假设与取舍

* 字阶以「角色」命名而非「尺寸」命名，避免以后改数值时全站搜索。
* `SectionLabel` 从 13/dim 升到 15/600/ink78% 会改变全 App 卡片标题观感，属预期收益；若某页空间紧张，允许在调用处用 `Modifier` 微调间距，但不改字号。
* 批量替换只做等价映射，不做减法（不擅自删文案、不合并控件），把结构性问题留给第五节。
