# 通勤胶囊：节间时长按节点序列重排

## 概要

「算法学习」的「节间时长」按真实节点序列排列：

```
出发 → 进站 → 上车（出发站） → 下车（换乘） → 上车（换乘） → 下车（目的站） → 出站 → 到达
```

对应条目：

1. 出发→进站（新增学习项）
2. 进站→上车（出发站）（现有 `WAIT`）
3. 上车（出发站）→下车（换乘）/ 下车（目的站）（复用每段乘车样本）
4. 下车（换乘）→上车（换乘）（现有 `TRANSFER`）
5. 多段时重复 3、4
6. 下车（目的站）→出站（现有 `EXIT_WALK`）
7. 出站→到达（现有 `LAST_WALK`）

序列之后继续列出辅助项：提醒→确认下车、上车时刻、行程段时长、公交沿线速度，最后是全程时长。

## 现状分析

- 节间列表生成：[LearnReport.build()](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/LearnReport.kt#L45-L68)，当前每段混排 `进站→上车 / 下车→出站 / 提醒→确认 / 换乘步行 / 行程段时长 / 上车时刻 / 公交速度`，最后 `下车→到达 / 全程时长`，与节点顺序不一致，也缺「出发→进站」「上车→下车」。
- 指标定义：[Learn.Metric](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/Learn.kt#L279-L288)，没有「出发→进站」。

### 4. LearnReport.kt：按节点序列生成 `nodes`

文件：[LearnReport.kt](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/LearnReport.kt#L45-L68)

重写节点列表组装：

```kotlin
val last = trip.legs.lastIndex
fun boardName(i: Int) = if (i == 0) "上车（出发站）" else "上车（换乘）"
fun alightName(i: Int) = if (i == last) "下车（目的站）" else "下车（换乘）"
fun legSuffix(i: Int) = if (trip.legs.size > 1) " · 第 ${i + 1} 段" else ""

val nodes = mutableListOf<Line>()
// ① 出发 → 进站
nodes += statLine("出发→进站", Learn.nodeStat(ctx, Learn.Metric.APPROACH, "${trip.id}#0"))
trip.legs.indices.forEach { i ->
    val suffix = legSuffix(i)
    // ② 进站/换乘站 → 上车
    nodes += statLine("进站→${boardName(i)}$suffix",
        Learn.nodeStat(ctx, Learn.Metric.WAIT, "${trip.id}#$i"))
    // ③ 上车 → 下车（复用每段乘车样本，单位分钟）
    val rs = Learn.rideStat(ctx, trip.id, i)
    nodes += if (rs.values.isNotEmpty()) {
        val med = rs.values.sorted()[rs.values.size / 2]
        Line("${boardName(i)}→${alightName(i)}$suffix", "$med 分钟",
            "已学到 · ${rs.values.size} 次样本", true)
    } else {
        Line("${boardName(i)}→${alightName(i)}$suffix", "暂无样本", "跑一次这趟行程后生效", false)
    }
    // ④ 下车 → 上车（换乘）
    if (i > 0) {
        nodes += statLine("下车（换乘）→${boardName(i)}$suffix",
            Learn.nodeStat(ctx, Learn.Metric.TRANSFER, "${trip.id}#$i"))
    }
}
// ⑤ 下车（目的站）→ 出站
nodes += statLine("${alightName(last)}→出站",
    Learn.nodeStat(ctx, Learn.Metric.EXIT_WALK, "${trip.id}#$last"))
// ⑥ 出站 → 到达
nodes += statLine("出站→到达", Learn.nodeStat(ctx, Learn.Metric.LAST_WALK, trip.id))

// —— 辅助项：序列之后继续列出 ——
trip.legs.indices.forEach { i ->
    val suffix = legSuffix(i)
    nodes += statLine("提醒→确认下车$suffix", Learn.nodeStat(ctx, Learn.Metric.REACT, "${trip.id}#$i"))
    val bc = Learn.boardClockStat(ctx, trip.id, i)
    val med = bc.median
    val clockLabel = if (i == 0) "上车时刻（出发站）$suffix" else "上车时刻（换乘）$suffix"
    nodes += if (med != null) {
        Line(clockLabel, mm(med), "已学到 · ${bc.values.size} 次人工样本", true)
    } else {
        Line(clockLabel, "样本不足", "${bc.values.size}/${bc.need} 次人工样本", false)
    }
    nodes += statLine("行程段时长$suffix", Learn.nodeStat(ctx, Learn.Metric.LEG_SPAN, "${trip.id}#$i"))
    Learn.busSpeed(ctx, trip.id, i)?.let {
        nodes += Line("公交沿线速度$suffix", "${it.toInt()} 米/分钟", "指数平均", true)
    }
}
nodes += statLine("全程时长", Learn.nodeStat(ctx, Learn.Metric.TRIP, trip.id))
```

说明：

- 「进站→上车」对换乘段标签为「进站→上车（换乘）」略拗口，实际含义是「到站→上车」，按用户给定节点名保持「进站→上车（换乘）」写法，仅换乘段如此。
- 「上车→下车」直接复用 `Learn.rideStat`（分钟），与「每段乘车」卡片同源，不新增指标。
- 辅助项顺序：提醒→确认、上车时刻、行程段时长、公交速度（逐段），最后全程时长。

### 5. 无需改动

- 学习写入规则（人工优先、自动兜底）、一键重学入口与页面渲染（`NodeLines` 已全量列出）不变。

## 假设与决策

- 「上车→下车」复用每段乘车样本，不新增重复学习指标（用户选择「补齐两项」的前提）。
- 「出发→进站」只在有 `ENTER` 节点的首段（地铁）有效；公交首段没有进站节点，保持「暂无样本」。
- 非节点间隔项（提醒→确认、上车时刻、行程段时长、公交速度、全程）在节点序列之后继续留在同一卡片（用户选择）。
- 每段乘车卡片保留，不做删除；节间卡片中的「上车→下车」与其数据一致。
