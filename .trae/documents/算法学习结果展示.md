# 增加「算法学习结果」只读总览页

## 一、Summary

在设置页新增二级页面「算法学习」，只读展示本机已经学到的所有关键常量：

- 每条行程：习惯上车时刻、每段当前采用的乘车时长及来源、五类节点时长（候车/换乘/出站/末段步行/反应）、首末段步行时长；
- 全局：站间行车时长（按线路）、地铁班次偏差（按站+线+方向+峰期）、家/公司学习进度。

不提供任何修改或清空入口；异常样本仍通过「行程记录 → 删除记录」回滚。全部数据来自本机 SharedPreferences，不联网、不上传。

## 三、Proposed Changes

### 1. `Learn.kt`：增加只读统计 API（不改任何写入/预测逻辑）

在文件末尾新增一节 `// ---------- 只读报表 ----------`，复用已有的 private 读取函数：

```kotlin
data class Stat(val values: List<Int>, val need: Int) {
    val median: Int? get() = if (values.size >= need) values.sorted()[values.size / 2] else null
}

data class HabitStat(val days: Int, val typical: Int?, val needDays: Int)
data class StopLineStat(val lineKey: String, val perHop: Stat, val pairs: List<Pair<String, Stat>>)
data class MetroStat(val stop: String, val line: String, val dir: String, val peak: Boolean, val sec: Int)

fun habitStat(ctx: Context, tripId: String, dow: Int): HabitStat
fun rideStat(ctx: Context, tripId: String, legIdx: Int): Stat      // need = 3
fun nodeStat(ctx: Context, m: Metric, scope: String): Stat         // need = m.minSamples
fun stopStats(ctx: Context): List<StopLineStat>
fun metroStats(ctx: Context): List<MetroStat>
```

实现要点：

- `habitStat`：用已有的 `entries()` + `typicalBoard()`。`needDays` 按现有规则返回 3 或 5（同星期满 3 天，否则总体满 5 天）。
- `rideStat`：`RIDE` 下 `"$tripId#$legIdx"` 的分钟数组，`need = 3`。
- `nodeStat`：`nodeEntries()` 过滤 `metric.range`，`need = metric.minSamples`。
- `stopStats`：读 `STOPS` 的全部键：
  - `a|<lineKey>` → 该线路每站样本，`need = 2`；
  - `p|<lineKey>|<from>|<to>` → 从右往左解析（`lineKey` 自身含一个 `|`）：`to = substringAfterLast('|')`，`from = 剩余.substringAfterLast('|')`，`lineKey = 剩余.substringBeforeLast('|')`。
  - 按 `lineKey` 聚成 `StopLineStat`，每站中位直接复用 `stopMedian`，`pairs` 用 `"from → to"` 作为展示键。
- `metroStats`：遍历 `METRO` 的所有键（`getAll()`），解析 `站名|线路|方向|p/o`，保留偏差为 0 的键（表示已学但无偏差）。
- 所有新函数只读，不写 prefs、不调用 `journalNote`。

### 2. 新建 `LearnReport.kt`：把学习数据组装成页面模型

路径：`app/src/main/java/com/busnotice/commute/LearnReport.kt`

```kotlin
object LearnReport {
    data class Line(val label: String, val value: String, val note: String, val ready: Boolean)
    data class LegLine(val index: Int, val title: String, val ride: String, val source: String, val samples: String)
    data class TripBlock(val name: String, val habit: Line, val walks: List<Line>, val legs: List<LegLine>, val nodes: List<Line>)
    data class StopBlock(val line: String, val perHop: String?, val pairs: List<Pair<String, String>>)
    data class MetroBlock(val stop: String, val line: String, val dir: String, val peak: Boolean, val offset: String)
    data class PlaceBlock(val name: String, val progress: String, val confirmed: Boolean)
    data class Report(val trips: List<TripBlock>, val stops: List<StopBlock>, val metros: List<MetroBlock>, val places: List<PlaceBlock>)

    fun build(ctx: Context): Report
}
```

组装规则：

- 遍历 `TripStore.all(ctx)`，为每条行程生成一个 `TripBlock`：
  - `habit`：`Learn.habitStat(ctx, trip.id, 今天 dow)` → `"通常 08:12"`；未满阈值时 `"样本 2 天，还差 3 天"`，`ready = false`。
  - `walks`：首段/末段步行，`WalkLearn.samples(..., "first"/"last")`，展示 `"6 分 12 秒 · 5 次"`；不足 3 次时 `"样本 2/3 次"`。末段同时提示当前兜底值 480 秒（仅文案）。
  - `legs`：每段调用 `Learn.ride(ctx, trip.id, i, leg)` 得到当前采用值，来源转文案：`LEARNED→实测`、`MANUAL→手填`、`ESTIMATE→按站数估算`、`DEFAULT→预设`；再拼 `rideStat` 的样本数 `"n 次实测"`。
  - `nodes`：`WAIT`、`TRANSFER`（仅 i>0）、`EXIT_WALK`、`REACT` 按段循环，`LAST_WALK` 用 `trip.id` 作用域；展示值或 `"样本 n/阈值"`。公交速度非空时追加一行 `"沿线速度 312 米/分钟"`。
- `stops`：`Learn.stopStats(ctx)`，把 `lineKey` 拆成 `"线路 · 方向/终点"` 展示，`pairs` 转 `"A → B"`。
- `metros`：`Learn.metroStats(ctx)`，峰期显示 `"高峰"/"平峰"`，偏差显示 `"实际约晚 35 秒"` / `"基本准时"`。
- `places`：`Places.progressOf(ctx, HOME/WORK)` 与 `bothConfirmed`，展示 `"家 3/3 · 已确认"`。
- 时间/时长格式化放在该文件私有函数：`mm(min)`、`dur(sec)`（分+秒）。

## 四、Assumptions & Decisions

- 只读：不提供清空/重置按钮（用户已选择「只读总览」）；回滚继续走行程记录删除。
- 展示范围：Learn 全部样本 + WalkLearn（首/末段）+ Places（家/公司）。不展示公交到站历史（`BusTimetable`）和地铁基站 E1 模型——两者没有现成的只读汇总 API，且数据量大，本次不扩大范围。
- 乘车时长展示采用 `Learn.ride(ctx, tripId, legIdx, leg)`（不带地铁按站估算），来源标为「预设」时补充说明“地铁段运行时可能按站数估算”，避免误导。
- `autoAdjust / suggest` 目前无调用点，本页面也不展示，避免暗示会自动调整时间窗。
- 页面不写入任何数据，打开页面不会影响学习结果。
