# 行程详情：节点时间轴精简 + 到站打卡时间轴

## 一、概述

「行程详情」里两张时间轴类卡片存在两类问题：

1. 「节点时间轴」每行右侧多一列文字来源（自动/刷卡/手动/推算/补录），而时间颜色已经表达同一信息，列冗余、行更挤。
2. 「到站打卡」名字与实际形态不符（是时间轴不是打卡按钮），站点行样式也比节点时间轴弱：字号偏小、时间灰色、无分隔线。

方案：删掉第三列，用一行统一图例解释颜色；「到站打卡」更名「到站打卡时间轴」，站点行完全对齐节点时间轴（名称 14sp ink、时间 14sp 等宽满色 + 语义色、行间分隔线）。只改 `ui/RecordsScreen.kt`，不动数据与学习逻辑。

## 二、现状分析（RecordsScreen.kt）

- 节点时间轴：`GlassCard` + `SectionLabel("节点时间轴")`，行结构为「名称 80dp / 时间 14sp Bold 语义色 / Spacer / `srcText` 来源列」（:231-258）。
- 颜色语义已经承载来源：刷卡→绿、补录→黄、推算→dim、自动/手动→ink（:245-251）。
- 到站打卡：`SectionLabel("到站打卡")`（:269），站点行由 `StopRow` 渲染——名称 `Type.BodyDim`、时间 `Type.BodyDim` + dim、无分隔线（:358-369）。
- 首末站时间来自「确认上车 / 我已下车」节点（:305-314），没有来源标注，视觉上也和手动打卡无法区分。
- `srcText()`（:386-393）仅被来源列使用，删除列后会变成死代码。

## 三、设计决策

1. **删列不删语义**：节点时间轴删掉来源列，在标题下方加一行 `Type.Caption` 图例：`绿色＝刷卡或手动 · 黄色＝补录 · 浅色＝推算 · ≈＝估算`。
2. **颜色映射与看板对齐**：记录详情中 `MANUAL` 也归入绿色（当前是 ink），`TAP`/`MANUAL` → 绿，`BACKFILL` → 黄，`ESTIMATED` → dim，`AUTO` → ink，缺失 → dim 50%。这样图例对两张页面都成立。
3. **到站时间是时间轴**：更名为「到站打卡时间轴」；行样式与节点时间轴一致——名称 `Type.Body` + ink、时间 14sp Bold tnum、行间 1dp hairline、上下 7dp。
4. **到站行的颜色也表达来源**：手动站点打卡 → 绿；首站取「确认上车」、末站取「我已下车」时，沿用该节点的 src 颜色；无记录 → dim 的「—」。
5. 「共 N 次」改为「手动打卡 N 次」，避免与时间轴里补位出来的首末站混淆。

## 四、具体改动（`ui/RecordsScreen.kt`）

1. **新增私有工具**
   ```kotlin
   private fun srcColor(src: NodeLog.Src?, dark: Boolean): Color = when (src) {
       NodeLog.Src.TAP, NodeLog.Src.MANUAL -> Fuse.BusGreen
       NodeLog.Src.ESTIMATED -> Fuse.dim(dark)
       NodeLog.Src.BACKFILL -> Fuse.Yellow
       else -> Fuse.ink(dark)
   }
   ```
2. **节点时间轴（:231-258）**
   - `SectionLabel("节点时间轴")` 下加图例 `Text(legend, style = Type.Caption, color = dim)`，再用 4dp 间距接第一行。
   - 行内删除 `Spacer(weight)` 与 `srcText(...)`；时间颜色改调 `srcColor(st?.src, dark)`，`st == null` 时 `dim.copy(alpha = 0.5f)`。
   - 保留「≈」前缀与 80dp 名称列。
3. **删除 `srcText()`（:386-393）**，确认无其他调用。
4. **到站打卡时间轴（:266-321）**
   - 标题改「到站打卡时间轴」；`共 N 次` → `手动打卡 N 次`，仅 `r.marks.isNotEmpty()` 时显示。
   - 站点行统一走改造后的 `StopRow`：
     ```kotlin
     @Composable
     private fun StopRow(
         name: String, at: Long?, timeColor: Color, dark: Boolean, divider: Boolean,
     )
     ```
     名称 `Type.Body` + `Fuse.ink(dark)`、`weight(1f)`、单行省略；时间 `14.sp` + `FontWeight.Bold` + `TnumStyle`、颜色 `timeColor`、「—」用 `Fuse.dim(dark).copy(alpha = 0.5f)`；`divider` 为 true 时行后画 1dp `Fuse.hairline(dark)`。
   - 调用处计算颜色：
     - `marked != null` → `Fuse.BusGreen`；
     - `idx == 0` 且用 `boardAt` 补位 → `srcColor(eff[BOARD]?.src, dark)`；
     - `idx == names.lastIndex` 且用 `alightAt` 补位 → `srcColor(eff[ALIGHT]?.src, dark)`；
     - 其它无值 → `Fuse.dim(dark)`。
     - `divider = idx != names.lastIndex`。
   - 旧记录分支（`legacyNames`，:276-280）同样调用新 `StopRow`，`marks` 命中的时间用绿色，无值用 dim。
   - 段标题（序号 + 线路牌 + 往X / 段名）保持不变。

## 五、假设与取舍

- 图例只放在「节点时间轴」一张卡内，满足「同一说明」；到站时间轴的绿色复用同一套语义，不再重复图例。
- 时间 14sp Bold 沿用节点时间轴现状，不套用算法学习的降噪规则（这是行程详情，不是统计页）。
- 颜色映射调整（MANUAL 由 ink 改绿）只影响记录详情展示，不改任何存储或学习数据。
