# 通知按钮统一改为「点击通知 + 动宾说明」

## 摘要

把系统通知里所有会产生副作用的按钮，统一改成「点击通知 + 动宾结构 + 作用」的句式，让用户在通知栏里不用回忆上下文就能判断点了会发生什么。App 看板内的按钮保持现有措辞（有行程上下文）。

## 改动方案

### 1. `LiveNotifier.kt` — 通知按钮文案

逐条替换（文案含一个半角空格）：

```kotlin
// L190 到站提醒
b.addAction(0, "点击通知 停止本次下车提醒", actionIntent(ctx, ActionReceiver.ACTION_ALIGHT_KNOW))
// L191 到站提醒
b.addAction(0, "点击通知 确认下车", actionIntent(ctx, ActionReceiver.ACTION_ALIGHT_ACK))

// L301-L305 常驻胶囊
if (v.riding) addAction(0, "点击通知 确认下车", actionIntent(ctx, ActionReceiver.ACTION_ALIGHT_ACK))
else if (CommuteService.undoActive()) addAction(0, "点击通知 撤销上车", actionIntent(ctx, ActionReceiver.ACTION_BOARDED))
else addAction(0, "点击通知 确认上车", actionIntent(ctx, ActionReceiver.ACTION_BOARDED))
...
.addAction(0, if (v.riding) "点击通知 结束本次行程" else "点击通知 结束本次提醒",
    actionIntent(ctx, ActionReceiver.ACTION_STOP))

// L98 步行记录
.addAction(0, "点击通知 停止记录", actionIntent(ctx, ActionReceiver.ACTION_STOP))
```

- 「停止本次下车提醒」明确是"停这一次的提醒"，不是关闭整个功能；「确认下车 / 确认上车」是动宾，且点下去就写真实时间。

## 假设与决策

- **句式**：严格用「点击通知 + 空格 + 动宾」；不额外加冒号或括注，保证同类按钮一致。
- **只改通知，不改 App 看板**：看板有行程上下文，继续用「我知道了 / 我已下车」。
- **不新增动词，不改动作绑定**：只换文案，`ACTION_*` 与行为完全不变。
- **「撤销上车」保留原动词**：它只是把刚记录的上车时间撤掉，无需改成"确认"。
- **「结束行程 / 结束本次提醒」按是否在车上区分**：与现有 `v.riding` 分支一致。
- 构建沿用既有约定：本地 Gradle + `adb install -r`，不推 GitHub；版本号 `0.4.6-dev.48`。
