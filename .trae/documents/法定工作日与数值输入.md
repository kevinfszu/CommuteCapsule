# 法定工作日（在线获取并本地缓存）与数值直接输入

## Summary

1. **哪几天增加「法定工作日」**：在周一至周日多选之外新增该模式。开启后按中国法定节假日安排判断：法定节假日不提醒，调休上班的周末照常提醒。
2. **节假日数据按年在线获取并落盘**：本地没有某年数据时，调用免费接口 `timor.tech` 拉取并保存；之后离线读取缓存，不重复请求。跨年后自然命中新一年缺数据 → 再拉一次并保存。
3. **步进器支持直接输入**：`Stepper` 中间的数值改为可编辑数字框，可直接输入「45」，同时保留 −/+ 按钮；「大约坐多久」「换乘步行」等所有使用 `Stepper` 的地方都生效。

## Proposed Changes

### 1. 新增 `ChinaWorkdays.kt`（在线获取 + 本地缓存）

新文件 `app/src/main/java/com/busnotice/commute/ChinaWorkdays.kt`：

```kotlin
object ChinaWorkdays {
    private const val BASE = "https://timor.tech/api/holiday/year/"
    private const val PREFS = "china_workdays"   // year_2026 -> 原始 JSON；try_2026 -> 上次尝试时间
    private const val RETRY_MS = 6 * 60 * 60 * 1000L

    data class Year(val offDays: Set<LocalDate>, val workDays: Set<LocalDate>) {
        fun isWorkday(d: LocalDate): Boolean = when {
            d in workDays -> true
            d in offDays -> false
            else -> defaultIsWorkday(d)
        }
    }

    fun init(ctx: Context)        // 保存 applicationContext，载入缓存，并 ensure(今年，12 月再加明年)
    fun isWorkday(date: LocalDate): Boolean  // 有缓存按缓存；缺失先回退周一至周五，同时触发 ensure
    fun ensure(vararg years: Int)            // 缺数据才异步拉取
    internal fun parse(year: Int, raw: String): Year?
    internal fun defaultIsWorkday(d: LocalDate): Boolean  // 周一–周五
}
```

* **读取**：内存 `ConcurrentHashMap<Int, Year>` 优先；未命中再读 `SharedPreferences` 的 `year_<year>` 原始 JSON 并解析缓存。
* **拉取**：`ensure` 只针对「缓存缺失」的年份；用 `fetching` 集合 + `try_<year>` 时间戳做 6 小时冷却，避免失败时频繁请求。协程跑在 `Dispatchers.IO`，复用 `RemoteTransit.fetch("$BASE$year/")`。
* **保存**：先 `parse` 校验（`code == 0` 且有 `holiday` 对象），成功才写入 `year_<year>`；原始 JSON 落盘，下次启动直接离线解析。
* **解析**：遍历 `holiday` 的每个 `MM-DD`，优先用条目里的 `date`，没有就用 `"$year-$key"`；`holiday == true` 进 `offDays`，`false` 进 `workDays`。格式异常/HTML 验证页 → 返回 null，记 `Diag.mark`，保持周一至周五回退。
* **成功后**：主线程 `Handler(Looper.getMainLooper()).post { Scheduler.rescheduleAll(app) }`，用新数据重排已存在的闹钟（此前可能按周一至周五排过）。
* **跨年**：缓存按年分 key，1 月 1 日查新一年必然缺失 → 自动拉取并保存；`init` 在 12 月会额外 `ensure(明年)`，避免元旦当天还没数据。

### 6. `TripEditor.kt`：`Stepper` 数值可编辑

把中间 `Text("$value $unit")` 换成数字框，布局仍为 label（weight 1） − 「数字 + 单位」 +。

* 状态与提交：

```kotlin
var text by remember { mutableStateOf(value.toString()) }
LaunchedEffect(value) { if (text.toIntOrNull() != value) text = value.toString() }

fun commit() {
    val parsed = text.toIntOrNull()?.coerceIn(min, max) ?: value
    if (parsed != value) onChange(parsed)
    text = parsed.toString()
}
```

* `BasicTextField`：
  * `onValueChange` 只留数字并 `take(3)`；解析值在 `min..max` 内立即 `onChange`（边输边生效），越界先保留文本，Done/失焦时夹到边界。
  * `KeyboardOptions(keyboardType = KeyboardType.Number, imeAction = ImeAction.Done)`；`KeyboardActions(onDone = { commit(); focusManager.clearFocus() })`。
  * `Modifier.width(46.dp).onFocusChanged { if (!it.isFocused) commit() }`，文字居中、`TnumStyle`、15sp 加粗、主色；外层 `clip(RoundedCornerShape(8.dp))` + 浅色背景提示可点，后面紧跟 `Text(" $unit")`。
* −/+ 按钮逻辑不变；`value` 变化时 `LaunchedEffect` 同步文本。

## Assumptions & Decisions

* **不内置节假日表**：按年从 `timor.tech` 获取，成功才落盘；同一年的数据不重复拉取，失败 6 小时后再试。
* **离线兜底**：当年数据尚未拿到或请求失败时，先按周一至周五判断，不影响其他功能；成功后重排闹钟。
* **法定工作日是独立模式**：忽略 `dayMask`，但保留其值；点任意星期 chip 即切回自定义模式。
* **跨年自动更新**：缓存按年份分 key；12 月预取明年，1 月 1 日缺失也会即时触发。
* **只看中国内地**，港澳台/境外不处理。
* `nextTrigger` 向后找 15 天，覆盖春节 9 天长假。
* 学习上车时间仍按星期几记录；调休周六首次走默认时间。
* 数值输入只改 `Stepper`；`HeadwayStepper`（发车间隔分/秒）不在本次范围。
