# 到站提醒：过完最后一个中间站才强提醒，静音与数据记录分离

## 摘要

1. 提醒**只在过完最后一个中间站之后**触发，取消「还有 2 站」和时间提前触发。
2. 触发后是**强提醒**：闹钟音 + 振动 + 高优先级通知，循环响铃，防止睡着/走神坐过站。
3. **静音与数据记录分离**：
   - 「我知道了」＝ 只是承认收到提醒，立刻停止响铃/振动，**不记任何时间、不参与学习**；
   - 「我已下车」＝ 记录真实下车时刻，供算法学习，同时自然静音。
4. 打卡是事实：位置、进度、剩余站数、提醒阶段都按最近一次打卡实时重算；选站窗口仍为 ±5 站，中心为真实位置。

## 两个按钮的分工（核心设计）

| 按钮 | 作用 | 写数据 | 停止响铃 |
| --- | --- | --- | --- |
| 我知道了 | 防坐过站/走神，确认"人醒着、听到了" | 否 | 当前阶段静音 |
| 我已下车 | 人工记录真实下车时刻 | 是（ALIGHT 节点、学习样本） | 是，并结束本段/行程 |

- 只有「我已下车」会调用现有的 `ackAlight()`；「我知道了」走新的 `muteAlarm()`。
- 静音只对**当前阶段**生效：`alarmMutedStage` 记住被静音的阶段。阶段从 T1 → AT → OVERSHOOT 升级时会重新响铃（快到站、已到站、过站是三种不同风险，必须重新提醒）。
- 静音后通知保留（带两个按钮），不再响铃；用户真下车时再点「我已下车」记录时刻，数据不受"嫌吵"影响。

## 提醒触发条件（按本次行程实例说明）

13 号线 白江 → 天河公园，站序：

```
白江(0) … 沙村(1) … 车陂(9) 天河珠村(8) 棠下(10) 天河公园(11=下车站)
```

- **全程不提醒**：还剩 2 站及以上（车陂、天河珠村、棠下途中都不响）。
- **第一次强提醒**：已过完「棠下」，下一站就是「天河公园」（`remaining <= 1`）。
- **最强档**：定位或车厢播报确认已到「天河公园」（`atStation`），直接「现在下车」。
- **压制**：新鲜定位显示离下车站还很远（`far`）时保持安静。
- 取消原来「按预计到达时间提前 X 秒提醒」的逻辑（这是车陂一带就提前响的原因）。

## 强提醒规格

| 阶段 | 条件 | 声音 | 间隔 | 次数 | 通知按钮 |
| --- | --- | --- | --- | --- | --- |
| T1 准备下车 | `remaining <= 1` | 闹钟音 3 秒 + 振动 | 20 秒 | 8 | 我知道了 / 我已下车 |
| AT 现在下车 | 定位/播报确认到站 | 闹钟音 3 秒 + 振动 | 15 秒 | 8 | 我知道了 / 我已下车 |
| OVERSHOOT 已过站 | 到站后仍未记录下车 | 闹钟音 4.5 秒 + 振动 | 20 秒 | 3 | 我知道了 / 我已下车 |

- 次数用完后：不再响铃，通知常驻，两个按钮仍可用。
- 静音条件：点「我知道了」（当前阶段）、点「我已下车」、进入下一段、行程结束。

## 改动方案

### 1. `AlightGuard.kt`

- 删除 `Stage.T2` 及文案，阶段保留 `NONE / T1 / AT / OVERSHOOT`。
- `Input` 去掉 `etaKnown / eta / leadMs`，保留 `remaining / atStation / acked / overshoot / far`。
- `stage()`：
  ```kotlin
  if (i.acked) return Stage.NONE
  if (i.overshoot) return Stage.OVERSHOOT
  if (i.far) return Stage.NONE
  if (i.atStation) return Stage.AT
  if (i.remaining <= 1) return Stage.T1
  return Stage.NONE
  ```
- `shouldRing`：T1 / AT / OVERSHOOT 均为 true。
- `maxRings`：T1 = 8、AT = 8、OVERSHOOT = 3。
- `intervalMs`：T1 = 20 秒、AT = 15 秒、OVERSHOOT = 20 秒。

### 2. `LiveNotifier.kt`：通知加「我知道了」

- `alert(...)` 增加 `quiet: Boolean = false`：为 true 时不弹流体云、不振动、`.setSilent(true)`，用于静音后刷新通知。
- `ack` 为 true 时同时添加两个动作：
  - 「我知道了」→ `ActionReceiver.ACTION_ALIGHT_KNOW`
  - 「我已下车」→ 现有 `ACTION_ALIGHT_ACK`
- 新增 `fun alightQuiet(ctx, title, text, metro, id)`（内部调 `alert(quiet = true, ack = true)`），静音后刷新一条不响的通知。

### 3. `CommuteService.kt` 内的 `ActionReceiver`

在现有 `ACTION_ALIGHT_ACK`（L2778）旁新增 `ACTION_ALIGHT_KNOW`，收到后调用 `svc.muteAlarm()`；不写任何节点。

### 4. `CommuteService.kt`

- 新增 `private var alarmMutedStage: AlightGuard.Stage? = null`。
- 新增：
  ```kotlin
  /** 「我知道了」：只停响铃，不记下车时刻，避免污染学习数据 */
  fun muteAlarm() {
      if (alightStage == AlightGuard.Stage.NONE) return
      alarmMutedStage = alightStage
      alightAlarmNextAt = 0L
      AlarmBuzzer.stop()
      fireAlight(alightStage, legIdx, System.currentTimeMillis(), force = true)  // 静音刷新通知
      TraceLog.event("alight_mute", "stage" to alightStage.name, "leg" to legIdx)
  }
  ```
- `fireAlight`：
  - 删除 T2 分支；T1 / AT / OVERSHOOT 统一发 `ack = true` 的通知；
  - 当 `alarmMutedStage == stage` 时只发 `alightQuiet(...)`，不响铃、不计数；
  - 阶段变化时（`stage != alightStage`）自动清空 `alarmMutedStage`，重新允许响铃；
  - T1 用 `AlarmBuzzer.ring`（3 秒），OVERSHOOT 用长响（4.5 秒）。
- `resetAlightGuard()` 里补 `alarmMutedStage = null`。
- `markStop(idx)` 追加打卡重锚：
  ```kotlin
  if (riding && alightAckedAt == 0L) {
      val left = (stopNamesOf(legIdx)?.size ?: 0) - 1 - idx
      if (left > 1 && arriveAlertedAt > 0L) {
          arriveAlertedAt = 0L; arriveAgainAt = 0L; overshootAlerted = false
          alightStage = AlightGuard.Stage.NONE; alightStageAt = 0L
          alightAlarmCount = 0; alightAlarmNextAt = 0L; alarmMutedStage = null
          AlarmBuzzer.stop()
          TraceLog.event("mark_reanchor", "leg" to legIdx, "idx" to idx, "left" to left)
      }
  }
  ```
  保留原有"打卡不回头"逻辑。
- `rideTick`：所有位置信息（`p`、`metroCur`、`title`、`text`、`stops`、`stopUi`、`names`）去掉 `arriveAlertedAt == 0L` 限制，只要 `mr != null` 就发布。提醒语气仍由 `arriveAlertedAt` 决定。
- 删除私有 `alertLeadMs()` 及 `AlightGuard.Input` 中的时间字段（`Learn.alertLeadMs` 的既有学习数据不动）。

### 5. `LiveBoard.kt`：恢复 ±5 窗口

把上一版全站列表改回窗口，中心用可信位置：

```kotlin
val markIdx = stopMarks.maxOfOrNull { it.idx }
val here = (listOfNotNull(s.stopsPassed, markIdx).maxOrNull() ?: 0)
    .coerceIn(0, stopNames.size - 1)
val from = (here - 5).coerceAtLeast(1)
val to = (here + 5).coerceAtMost(stopNames.size - 1)
val count = to - from + 1
```

高度按 `min(count, 8) * 46.dp` 显式给足（9 行以上必可滚动），初始滚动 `here - from - 2`；`count > 8` 时显示「共 $count 站，可上下滑动」。

### 6. 单测与文档

- `AlightGuardTest`：改 `input()`；`remaining = 2` → `NONE`；`remaining = 1` → `T1`；删除 ETA 提前触发用例；补 `shouldRing(T1)`、`maxRings(T1) == 8`。
- `CHANGELOG.md` `[未发布]`：到站提醒改为过完最后一个中间站才提醒；新增「我知道了」静音按钮，与「我已下车」的数据记录分离；打卡后按真实位置重算。

## 假设与决策

- 「过完最后一个中间站」= `remaining <= 1`；打卡后即为真实值。
- 「我知道了」只静音当前阶段；阶段升级重新响铃。
- 「我已下车」仍是唯一写入下车时刻的入口，学习样本不受静音动作影响。
- 有换乘的下车段与终点站同一强度。
- 只做本地构建 + `adb install -r`，不推 GitHub。
