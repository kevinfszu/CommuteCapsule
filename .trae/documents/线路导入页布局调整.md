# 线路导入页布局调整

## Summary

把「线路导入」页从「说明 + 列表 + 新增卡 + 危险卡」的纵向堆叠，改为：

1. 顶栏右上角只放两个圆钮：`＋`（新增）和 `⋯`（更多）。
2. `＋` 弹出菜单，集中两种新增方式：「导入 JSON 文件」「用高德查询并生成」。
3. `⋯` 弹出菜单，只放「清空全部线路」，点击后弹二次确认对话框。
4. 页面主体只保留顶部信息卡（当前数据源 + 说明 + JSON 格式提示）和已导入线路列表。
5. 移除页面底部的「新增线路」大卡、「危险操作」大卡和脚注。

## Current State Analysis

- [LineImportScreen.kt](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/LineImportScreen.kt) 当前结构：
  - `GlassPage(title = "线路导入", onBack = onBack)` 没有使用 `actions`；
  - 顶部依次是导入结果提示卡、「当前数据源」卡；
  - 中部是「已导入的线路」列表卡；
  - 下部是「新增线路」卡，里面两个全宽 `PillButton`；
  - 再往下是「危险操作」卡和 JSON 格式脚注。
- [GlassKit.kt](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/GlassKit.kt#L85-L93) 的 `GlassPage` 已经支持 `actions: @Composable RowScope.() -> Unit`，并交给 [GlassTopBar](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/GlassKit.kt#L124-L147) 渲染在标题右侧，不需要改基础组件。
- 首页已经使用同一套交互：[HomeScreen.kt](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/HomeScreen.kt#L511-L540) 用 `Box + RoundButton + DropdownMenu(shape = MenuShape, containerColor = Fuse.surface(dark))` 做 `⋯` 菜单；[HomeScreen.kt](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/HomeScreen.kt#L327-L339) 用 `AlertDialog(shape = DialogShape, containerColor = Fuse.surface(dark))` + `DialogButton` 做危险操作确认。
- 数据层无需改动：`Transit.importJson`、`Transit.clearImported`、文件选择器、`version`/`lastImport`/`confirmClear` 状态都可直接复用。

## Proposed Changes

只改 `app/src/main/java/com/busnotice/commute/ui/LineImportScreen.kt`，不改数据层、不改 `GlassPage`。

### 1. 顶栏：`＋` 与 `⋯`

给 `GlassPage` 增加 `actions`：

```kotlin
GlassPage(
    title = "线路导入",
    onBack = onBack,
    actions = {
        // ＋ 新增
        Box {
            RoundButton(
                onClick = { addMenu = true }, dark = dark,
                modifier = Modifier.semantics { contentDescription = "新增线路" },
            ) { Text("+", fontSize = 22.sp, fontWeight = FontWeight.Bold, color = ink) }
            DropdownMenu(
                expanded = addMenu, onDismissRequest = { addMenu = false },
                shape = MenuShape, containerColor = Fuse.surface(dark),
            ) {
                DropdownMenuItem(
                    text = { Text("导入 JSON 文件") },
                    leadingIcon = { Icon(Icons.Default.Add, null, Modifier.size(18.dp), tint = dim) },
                    enabled = !importing,
                    onClick = { addMenu = false; picker.launch(arrayOf("*/*")) },
                )
                DropdownMenuItem(
                    text = { Text("用高德查询并生成") },
                    leadingIcon = { Icon(Icons.Default.Search, null, Modifier.size(18.dp), tint = dim) },
                    enabled = !importing,
                    onClick = { addMenu = false; onOpenAmap() },
                )
            }
        }
        Spacer(Modifier.width(8.dp))
        // ⋯ 更多
        Box {
            RoundButton(
                onClick = { moreMenu = true }, dark = dark,
                modifier = Modifier.semantics { contentDescription = "更多" },
            ) { Text("⋯", fontSize = 16.sp, fontWeight = FontWeight.Bold, color = dim) }
            DropdownMenu(
                expanded = moreMenu, onDismissRequest = { moreMenu = false },
                shape = MenuShape, containerColor = Fuse.surface(dark),
            ) {
                DropdownMenuItem(
                    text = {
                        Text("清空全部线路", color = if (hasImport) Fuse.MetroRed else dim)
                    },
                    leadingIcon = {
                        Icon(Icons.Default.Delete, null, Modifier.size(18.dp),
                            tint = if (hasImport) Fuse.MetroRed else dim)
                    },
                    enabled = hasImport,
                    onClick = { moreMenu = false; confirmClear = true },
                )
            }
        }
    },
) { ... }
```

- 新增状态：`var addMenu by remember { mutableStateOf(false) }`、`var moreMenu by remember { mutableStateOf(false) }`。
- 菜单锚点用 `Box` 包裹圆钮，与首页 `⋯` 菜单一致。
- `importing` 时两个新增菜单项置灰，避免重复触发。

### 2. 顶部信息卡：收纳全部说明

保留第一项「导入结果提示」，并把「当前数据源」卡扩成唯一说明卡：

1. `SectionLabel("当前数据源")`
2. `Text("线路和站点：$sourceTitle")`
3. `noteText(meta)` 非空时显示来源/更新时间/备注小字
4. 新增一行 12sp `dim` 小字：
   `"JSON 格式见 docs/DATA_SOURCE.md。若行程进行中，请在导入后结束并重新开始。"`

删除页面最后的脚注 `item`，文案只保留在顶部信息卡里。

`importing` 时在信息卡上方显示一行提示卡：`"正在导入 JSON…"`，替代原来的按钮 loading 文案。

### 3. 主列表：保持并强化为主体

- 保留 `GlassCard(padding = 0.dp)` + 「已导入的线路（N 条）」标题 + `GlassRow` 列表，位置紧随顶部信息卡。
- 空状态文案改为：
  `"还没有导入线路。点右上角 ＋ 导入 JSON 或用高德生成。当前使用内置演示数据。"`
- 列表行支持点击进入详情，保持现有 `onOpenLine(name)`。
- 数据归并、摘要 `lineSummary` 不变。

### 4. 删除页面下部两张大卡

- 删除 `SectionLabel("新增线路")` 的整张 `GlassCard`，以及里面的两个 `PillButton`。
- 删除 `SectionLabel("危险操作")` 的整张 `GlassCard`，以及页内二次确认文案和按钮。

### 5. 清空改为对话框

在 `GlassPage` 之后保留一个 `AlertDialog`，样式对齐首页：

```kotlin
if (confirmClear) {
    AlertDialog(
        onDismissRequest = { confirmClear = false },
        shape = DialogShape, containerColor = Fuse.surface(dark),
        titleContentColor = ink, textContentColor = ink,
        title = { Text("清空全部线路？") },
        text = { Text("清空后所有已导入线路都会移除，并恢复内置演示数据。") },
        confirmButton = {
            DialogButton("清空", danger = true, onClick = {
                Transit.clearImported(ctx)
                version++
                lastImport = null
                confirmClear = false
                Toast.makeText(ctx, "已清空线路，恢复默认数据源", Toast.LENGTH_SHORT).show()
            })
        },
        dismissButton = { DialogButton("取消", onClick = { confirmClear = false }) },
    )
}
```

## Assumptions & Decisions

- 按确认结果：顶栏只放一个 `＋` 打开菜单，`⋯` 菜单放清空。
