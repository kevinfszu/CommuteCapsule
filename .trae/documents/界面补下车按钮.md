# 行程看板补「我已下车 / 我知道了」并规范通知按钮文案

## 摘要

乘车中看板的动作行只有「到站打卡」，临近终点站时既没有下车入口、也没有静音入口；这两个动作只存在于系统通知。本次：

1. 在 [LiveBoard.kt](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/LiveBoard.kt) 的动作行补「我已下车」「我知道了」，只在只剩本段下车站这一站时出现；
2. 把通知里会产生副作用的按钮改成**动宾结构 + 作用说明**（「停止响铃（不记下车）」「记录下车时间」等）；
3. 修正 `remaining = -1`（无站点数据）被当作「只剩 1 站」的问题；
4. 已确认下车后不再被后续播报重新拉起提醒（实测 08:11:25 下车后 08:11:41 又响过一次）。

## 事实核查：今早「下车 1 08:00」是怎么来的

从手机 `run_nodes.xml` 读到的当天记录（节点追加保存，`src` 是来源）：

| 节点       | 时间           | 来源         |
| -------- | ------------ | ---------- |
| 上车 1     | 07:24:44     | MANUAL     |
| **下车 1** | **08:00:03** | **MANUAL** |
| 上车 2     | 08:03:58     | MANUAL     |
| **下车 2** | **08:11:25** | **MANUAL** |
| 出站       | 08:11:49     | TAP        |
| 到达       | 08:13:58     | AUTO       |

* `MANUAL` 只会由 `ackAlight()` → `markAlight(now, "user")` 写入（[CommuteService.kt#L2715-L2721](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/CommuteService.kt#L2715-L2721)）。
* `ackAlight()` 的入口只有两个：**通知里的「我已下车」动作**；**节点时间轴里高亮的「下车 N」卡片**（点按 → `stampCurrentNode()` → `riding` → `ackAlight()`）。
* 当天轨迹（`files/traces`）显示换乘站 07:56:27 起连续弹「下一站下车「天河公园」」，07:59:08 起弹「现在下车「天河公园」」，08:00:03 才写入 ALIGHT——正是通知上那个按钮被点掉的时间；终点站 08:09:21 起同样连续弹「龙口西」，08:11:25 写入 ALIGHT。
* `git log -S'ackAlight' -- app/.../ui`、`git log -S'我已下车' -- app/.../ui` 均为空：**App 看板从未有过独立下车按钮**。

结论：换乘那次你点的"专门的下车按钮"就是**通知上的「我已下车」**（或节点条的「下车 1」卡片），和终点站那次是同一个入口。看板缺按钮属实；你之所以觉得换乘有、终点站没有，是因为换乘时直接从通知操作，终点站时在看板上找。

另外发现：轨迹里 08:11:25 已确认下车，08:11:41 播报又触发了一次 AT 提醒（`rings:1`），因为 `fireAlight` 不检查 `alightAckedAt`。这会让看板按钮在点完后"复活"，一并修掉。

## 改动方案

### 1. `CommuteService.kt` — 状态与提醒守卫

**a. `LiveSnapshot` 增加只读字段**（默认 false，带 JSON 存取）：

```kotlin
val alightDue: Boolean = false,   // 只剩本段下车站，等用户确认下车
```

* `toJson`：`.put("alightDue", s.alightDue)`；`fromJson`：`o.optBoolean("alightDue")`。
* `rideTick` 发布处（[CommuteService.kt#L1766-L1769](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/CommuteService.kt#L1766-L1769)）加：
  ```kotlin
  alightDue = st != AlightGuard.Stage.NONE && alightAckedAt == 0L,
  ```
  `st` 与响铃同源（T1/AT/OVERSHOOT），界面与提醒不会不同步；点过「我已下车」后 `st` 变 NONE，字段自动回 false。

**b. `fireAlight` 顶部加守卫**（[CommuteService.kt#L614](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/CommuteService.kt#L614)）：

```kotlin
if (alightAckedAt > 0L) return   // 已确认下车：播报/时间兜底不得再把提醒拉起来
```

### 2. `AlightGuard.kt` — 无站点数据不当作「只剩 1 站」

* `Input.remaining` 注释：`-1 表示无站点数据`。
* `stage()`：`if (i.remaining <= 1)` → `if (i.remaining in 0..1)`。
* `AT` 的 `text` 改为：`"请立即下车；点「停止响铃」静音，点「记录下车时间」记时刻"`。

### 3. `AlightGuardTest.kt`

```kotlin
@Test fun noRouteDataIsQuiet() = assertEquals(Stage.NONE, AlightGuard.stage(input(remaining = -1)))
```

### 4. `ui/LiveBoard.kt` — 动作行加「我已下车 / 我知道了」

只改乘车中的分支（[LiveBoard.kt#L290-L299](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/ui/LiveBoard.kt#L290-L299)）：

```kotlin
when {
    canUndo -> Pill("撤销上车", …)
    !s.riding -> Pill("确认上车", Fuse.Yellow, …)
    else -> {
        if (stopNames.size > 1) Pill("到站打卡", Color.White.copy(alpha = 0.12f), Color.White,
            Color.White.copy(alpha = 0.2f), Modifier.weight(1f)) { pickStop = true }
        if (s.alightDue) {
            Pill("我知道了", Color.White.copy(alpha = 0.12f), Color.White,
                Color.White.copy(alpha = 0.2f), Modifier.weight(1f)) {
                CommuteService.instance?.muteAlarm()      // 只静音，不写节点
            }
            Pill("我已下车", Fuse.Yellow, Color(0xFF111111), null, Modifier.weight(1f)) {
                CommuteService.instance?.ackAlight()      // 唯一记录真实下车时刻
            }
        }
    }
}
```

* 两个新按钮只在 `alightDue`（只剩本段下车站 / 已到站 / 已过站）时出现，与强提醒同窗口；乘车途中不出现。
* 顺序：到站打卡（次）→ 我知道了（次）→ 我已下车（主，黄底黑字）。
* 「我知道了」调既有 `muteAlarm()`：静音当前阶段、不写任何时间；阶段升级会重新响。

### 5. `LiveNotifier.kt` — 通知按钮改「动宾 + 作用」

`alert()` 的两个动作（[LiveNotifier.kt#L188-L192](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/LiveNotifier.kt#L188-L192)）：

```kotlin
b.addAction(0, "停止响铃（不记下车）", actionIntent(ctx, ActionReceiver.ACTION_ALIGHT_KNOW))
b.addAction(0, "记录下车时间", actionIntent(ctx, ActionReceiver.ACTION_ALIGHT_ACK))
```

常驻胶囊的动作（[LiveNotifier.kt#L300-L305](file:///e:/001-Program/CommuteCapsule/app/src/main/java/com/busnotice/commute/LiveNotifier.kt#L300-L305)）：

* `"我已下车"` → `"记录下车时间"`
* `"记：上车"` → `"记录上车时间"`
* `"撤销上车"`、`"结束行程"`、`"关闭提醒"` 保持（本身已是动宾、含义明确）

> App 界面有行程上下文，沿用熟悉的「我知道了 / 我已下车」；通知栏脱离上下文，按钮必须自带"点了会怎样"。

## 假设与决策

* **显示时机**：`alightDue`（`remaining in 0..1`，即过完最后一个中间站）时才出现，与强提醒同步。
* **App 与通知措辞不同**：App 有上下文用「我知道了 / 我已下车」；通知用「停止响铃（不记下车）/ 记录下车时间」。
* **`ackAlight()` 仍是唯一写真实下车时刻的入口**，通知与 App 共用。
* **不把「停止响铃」常驻**：只在提醒窗口出现，避免平时误触导致真正到站时不响。
* 构建沿用你的要求：本地 Gradle + `adb install -r`，不推 GitHub；版本号 `0.4.6-dev.47`。

## 验证

1. `gradle assembleDebug testDebugUnitTest` 全绿（含 `remaining = -1` 用例）。
2. `adb install -r` 后冷启动正常。
3. 真机/演示检查：
   * 乘车途中（剩 ≥2 站）：动作行仍只有「到站打卡」，无静音/下车按钮。
   * 只剩本段下车站：出现「我知道了」「我已下车」；点「我知道了」响铃立即停、节点条不新增记录、升到 AT 时重新响。
   * 点「我已下车」：节点条「下车 N」写入当前时间；之后即使播报"到了"也不再弹提醒、按钮不复活。
   * 通知栏展开：按钮为「停止响铃（不记下车）」「记录下车时间」；常驻胶囊为「记录下车时间 / 记录上车时间」。
   * 无路线数据的公交段：不会一上车就响铃；到站确认后按钮正常出现。
